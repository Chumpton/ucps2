# Unified Cosmic Positioning System (UCPS) Website

This project is a cosmic-themed website for the Unified Cosmic Positioning System, a multidimensional framework for locating beings across space, time, and consciousness.

## Project Structure

- `index.html`: Main entry point containing all content sections.
- `css/style.css`: Custom styling with a deep space aesthetic, glassmorphism, and animations.
- `js/app.js`: Logic for the interactive starfield background and scroll animations.
- `assets/`: Contains generated images for the background and compass application.

## How to Run

1.  Simply open `index.html` in your web browser.
2.  For the best experience, use a local development server (e.g., Live Server in VS Code, or `python -m http.server`).

## Features

- **Dynamic Starfield**: A canvas-based background that creates a sense of depth and motion.
- **Glassmorphism UI**: Modern, translucent cards and navigation.
- **Responsive Design**: Adapts for mobile and desktop screens.
- **Scroll Animations**: Content reveals smoothly as you explore the page.
